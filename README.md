# Salon Website

A modern salon website built with Vite, React, TypeScript, and Tailwind CSS.

## Features

- Home, Services, Gallery, Reviews, and Contact pages
- Responsive design for mobile, tablet, and desktop
- Reusable components and typed data models
- Modern salon branding and animation-driven UI

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- TanStack Router

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — lint the project

## Project Structure

```text
src/
  components/
  data/
  hooks/
  lib/

```
